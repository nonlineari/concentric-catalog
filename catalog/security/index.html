Catalog · security

Responsible state behaviour

The Global Mechanism on ICTs in the context of international security continues the OEWG track under UNODA. It is distinct from the UN Cybercrime Convention / Ad Hoc Committee: norms, international law application, CBMs, capacity — not criminal offences or LEA powers.

  • Intergovernmental; stakeholders in consultative roles
  • Five-year cycles with plenaries and dedicated thematic groups
  • Consensus, non-binding outputs — useful for floating models as norms or CBMs

Use this ring when the work is about state behaviour and peace/security, not indictment templates.
