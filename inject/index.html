How to inject a model into a forum

A reusable brief: pick the ring whose mandate can carry your model, then enter through that ring’s real door.

1 · Classify the payload

  • Offence / procedure / MLA → criminal-justice ring
  • Norm / CBM / state behaviour → security ring
  • Privacy / expression / remedy design → rights ring
  • Training curriculum / toolkit → capacity ring
  • Faster regional drafting → regional ring

2 · Map the entry door

  • Treaty: signature → domestic constitutional / parliamentary path → deposit
  • CSP / AHC protocol: rules of procedure, observer modalities, written contributions
  • Global Mechanism: plenary / DTG modalities, stakeholder consultative inputs
  • Rights: communications, UPR, Special Procedures calls, regional court interventions
  • Capacity: agency calls for tools, donor programme windows

3 · Write an injection brief

  1. One-sentence model claim
  2. Why this ring (mandate fit) and why not the others
  3. Exact procedural hook (session, agenda item, call for input)
  4. Domestic blockers if any (constitution, parliament, referendum rarity)
  5. What success looks like (cite, footnote, agenda language, toolkit adoption)
Keep operational exploit detail out of public briefs. Publish method and mandate fit here; keep teeth elsewhere.
